# MSDAA Text Mining — Group 42

NOVA IMS Master in Data Science and Advanced Analytics. Spring 2025/2026 course
project for Text Mining: 3-class sentiment classification on financial tweets,
combining frozen Transformer encoders with classical downstream classifiers.

**Best result: 0.794 macro-F1** (Twitter-RoBERTa + XGBoost, 5-fold stratified CV).
